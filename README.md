# Slow Drip

架空のカフェを想定して制作したWordPressオリジナルテーマです。
日々の情報はInstagramを中心に発信し、検索で訪れた人が店舗情報と重要なお知らせを確認できるサイトを想定しています。

[デモサイトを見る](https://wp001.akiyo-fukuhara.work)

## 主な機能

- レスポンシブ対応のトップページとスマートフォン用メニュー
- カスタムヘッダー画像を使ったヒーロースライダー（停止・再生操作、動きを減らす端末設定に対応）
- 固定ページから取得する店舗紹介、カスタム投稿タイプ「メニュー」、最新のお知らせ3件
- カスタマイザーから変更できるメインコピーと4枚のギャラリー画像
- 投稿・固定ページの確認用テンプレートと404ページ

## セットアップ

1. このリポジトリのファイルを wp-content/themes/slowdrip/ に配置し、WordPressの管理画面でテーマを有効化します。
2. 「設定→表示設定」で、トップページに任意の固定ページを指定します。トップページには front-page.php が使用されます。
3. 「外観→カスタマイズ」でカスタムロゴ、ヘッダー画像（スライド用）、メインコピー、ギャラリー画像（トップページ下部）を指定します。
4. スラッグが cafe_about の固定ページを作り、本文とアイキャッチ画像を設定します。トップページのAboutに表示されます。
5. 「メニュー」に名前とアイキャッチ画像を登録します。最大5件が表示されます。
6. 通常の「投稿」には重要なお知らせを登録します。新しいものから最大3件が表示されます。

## 補足

- ニュースやメニューのアーカイブへの導線は設けていません。投稿・固定ページの個別テンプレートは編集内容の確認用です。
- Instagramの投稿をAPIで埋め込む機能はありません。ギャラリー画像はカスタマイザーから設定します。
- 店舗名、メニュー、お知らせなどは架空のサンプルです。
- href="#" のリンクはデモ用です。
- 地図は公共の場所を示しています。
- ヒーロー画像や投稿内容など、WordPress管理画面で登録するデータはこのリポジトリに含まれません。
